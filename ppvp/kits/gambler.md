# 赌徒

常驻血量：20 BTK：5

普通攻击伤害：5.5

被动技能：

- **豪赌打击**：攻击时有20%概率造成3.5倍伤害。
- **破甲之赌**：当筹码500时，攻击有20%几率伤害x1.15（近似无视护甲）。
- **掠夺点券**：攻击时有 45%概率掠夺目标筹码。
- **锄地收益**：余额不足100时，锄地可获5筹码。  
  赌徒会随着筹码数量的增多获得越来越强力的增益效果。  

| 筹码  | 额外生命    | 常驻 Buff                            |
| ----- | ----------- | ------------------------------------ |
| ≥100  | +2（1 心）  | 速度 I                               |
| ≥250  | +4（2 心）  | 速度 I、抗性 I                       |
| ≥500  | +6（3 心）  | 速度 II、抗性 I、急迫 I              |
| ≥1000 | +10（5 心） | 速度 II、抗性 II、急迫 II、力量 I    |

筹码获取途径如下：

| 来源                     | 收益                                              |
| ------------------------ | ------------------------------------------------- |
| 定时收益                 | 每 10 秒 +8筹码，当筹码 ≥300 时停止                    |
| 掠夺点券（金锄攻击）     | 45% 概率 +2~5筹码                                     |
| 杀戮赏金（击杀）         | +50筹码                                               |
| 锄地保底（金锄右键草/土）| +5，1秒内置cd，仅筹码 <100 时可用                  |
| 死亡资产保护             | 保留死亡时 25%筹码（上限 100），若下局仍选赌徒则返还    |

技能：**命运轮盘**：可消耗15筹码进行抽卡，可能抽到的结果共五档，为JACKPOT(8%)/ WIN (32%) / DRAW (40%) / LOSS (16%) / BUSTED (4%)，每档内概率均分。  

-**★ JACKPOT类**：  
皇家同花顺：获得力量II 15秒；速度III 15秒； 生命恢复V 5秒，并增加300筹码。  
金币风暴：增加500筹码，并进行全服公告  
赌神姿态：30秒内金锄攻击必定触发**豪赌打击**。  

-**✔ WIN类**：  
筹码翻倍：当前筹码翻倍，单次增加上限150筹码。  
掠夺光环：8秒内每次攻击必定触发**掠夺点券**，且每次攻击增加22~25筹码（基础 2~5 再 +20）  
圣盾护体：获得伤害吸收V 20秒和抗性提升I 15秒。  
影之跃迁：获得隐身5秒及速度V 2秒。  
投机补给：获得八个末影珍珠或一个附魔金苹果。  

- **○ DRAW类**：  
运气守恒：增加15筹码（不盈不亏）。  
小赚一笔：增加30筹码（净赚15筹码）。  
战地医疗：获得瞬间治疗II ，并回满饱食度。  
环境自适应：获得抗火15秒或力量I 15秒。  
幻影潜行：静止3秒后进入永久隐身（若动则进入5秒衰减后消失）。  
幸运喷泉：掉落30点经验球。  

- **✘ LOSS类**：  
扣除20筹码。  
获得缓慢II 5秒。  
获得虚弱I 10秒。  
霉运缠身：15秒内所有攻击不会触发任何特效（特效包括掠夺/暴击/破甲）。  

- **☠ BUSTED类**：  
梭哈失败：清空全部筹码；若清空前不足 50 筹码则额外 扣 10 点血；补偿速度III 5秒。  
意外爆炸：85% 概率原地引爆TNT，15%概率TNT是哑弹（掉落一个 TNT 物品，免灾）；同样补偿速度 III。
