# 据点守卫

据点守卫会在据点附近生成  
据点守卫会攻击距离它11格内的玩家

**下列图片为例子**
![守卫](/img/guard.png)  
一个守卫有200滴血  
守卫有几个阶段

|          |    一阶段    |    二阶段    |   三阶段    |
| :------: | :----------: | :----------: | :---------: |
| 攻击伤害 |    1-2血     |     2血      |     2血     |
| 攻击冷却 |     1-2s     |     1-2s     |   0.5-1s    |
| 触发条件 | 自身血量>100 | 自身血量<100 | 自身血量<20 |

1阶段：发射白色激光  
2阶段：发射滚木  
3阶段：发射滚木爆炸，速度加快
