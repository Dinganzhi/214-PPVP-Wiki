# ID点歌

你可以在游戏内使用以下指令进行id点歌

```
/music <id>
```

注:<*id*>内的内容需要填为id，我们可以在网易云音乐客户端的分享中，点击分享链接获取音乐id  
下列是一个例子，拿《せかいから____がきえるとき》演示  
这首歌的链接为https://music.163.com/song?id=2082115896&uct2=U2FsdGVkX184ne7a8LKZ1k/ze1nKNUQxihu1bmT3CJE=  
注意**song?id=**后面的一串数字**2082115896**  
这就是歌曲的id  
因此我们在游戏内输入
```
/music 2082115896
```
点歌成功后，游戏会弹出下列提示:
![せかいから____がきえるとき](/music-wiki/m-help-game/png/suc.png)
客户端则会显示
![せかいから____がきえるとき](/music-wiki/m-help-game/png/せかいから____がきえるとき.png)
